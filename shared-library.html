Shared Library

One private bookshelf for two authorized members. Upload ZIPs once; both members can browse and read the uploaded EPUBs/PDFs from their devices.

Members only: Storage and downloads are authenticated. The existing public GitHub Pages books are still public; this new cloud bookshelf does not make those existing files private.
Cloud setup required. The private storage service and two-member authentication are not configured. No cloud upload is possible yet. See setup instructions.

Sign in with email

Only the two approved email addresses can access private cloud books. You'll receive a sign-in link.

If no email arrives, check the spam folder and the Supabase Auth configuration.

Private cloud storage

Upload ZIP files

Select one ZIP at a time. Athenaeum extracts the supported PDFs and EPUBs on this device and sends individual books to private cloud storage. The ZIP itself is not shared publicly.

PDF / EPUB; duplicate file hashes are skipped
Select a ZIP file to start.
Limits and privacy

ZIP archives are unpacked in your browser; large archives can exhaust browser memory. Files above 350 MB each are skipped. MOBI requires conversion to EPUB/PDF. Only authorized members can read books from this private bucket. Keep your original ZIP files as backups.
