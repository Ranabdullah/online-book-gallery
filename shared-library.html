Shared Library

One shared private bookshelf. You and your friend enter the same access code to upload and read books from different devices.

Code protected: Storage and downloads require your shared code. The existing public GitHub Pages books are still public; this new cloud bookshelf does not make those existing files private.
Cloud backend offline. The access code is not being rejected. Athenaeum has no deployed private-storage API to verify it against. Local ZIP imports are not shared. Cloud uploading and unlocking are unavailable until R2 and the Worker are configured. See setup instructions.

Only choose this on your own computer. Anyone using this browser profile could access the shared library.

Create a strong shared code

Generating a code does not activate it on the server. The same code must be saved privately as the Cloudflare Worker secret SHARED_ACCESS_CODE. Do not commit it to GitHub or post it in chat.

If you choose Remember this device, Athenaeum saves an encrypted browser-local credential. Lock Library clears it. Do not use this option on shared or public computers.

Limits and privacy

ZIP archives are unpacked in your browser; large archives can exhaust browser memory. Files above 350 MB each are skipped. MOBI requires conversion to EPUB/PDF. Only authorized members can read books from this private bucket. Keep your original ZIP files as backups.
