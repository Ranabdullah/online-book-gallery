# Offline Dictionary Attribution

`offline-dictionary.json` is generated from WordNet data supplied by the
`wordnet-db` package (version 3.1.14), distributed under the MIT License.

WordNet is a lexical database for English developed by Princeton University.
The bundled file contains a compact index of English headwords and their first
WordNet definitions for use inside this reader without an internet connection.

Source package: https://www.npmjs.com/package/wordnet-db
