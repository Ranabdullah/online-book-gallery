Automatic summaries for the whole catalog

Enable the repository's scheduled Gemini summarizer once, and it will work through the existing hosted books and pick up newly added GitHub-hosted titles. Completed source-based analyses are published for every visitor, rather than being saved only in this browser.

One-time setup: Add a GEMINI_API_KEY GitHub Actions repository secret using a new Gemini key, then select Run workflow in the automation.

Set the private Gemini key · Start automatic summaries · Setup and coverage details

The automation runs daily with a 20-book attempt cap. Each manual run can process up to 150 more. It skips completed books, retries failed files later and never invents content for unreadable sources. It does not publish private R2 book data to this public repository.
