Import a book ZIP

Review a folder archive and match PDFs/EPUBs to existing library entries, without creating duplicate titles.

Local import only. These files are stored in this browser's IndexedDB, not uploaded to GitHub, Supabase or Cloudflare. Other people cannot read your imported books. Keep the original ZIP until private cloud storage and account syncing have been activated. Large archives may exceed browser memory or storage quota; import on desktop, one archive at a time.

All newly imported entries from this ZIP receive the selected source marker and archive filename. Already hosted books retain their existing provenance.

Supports .pdf and .epub entries. Other file types will be listed as unsupported. Files are processed on your device.

Detected books

Matched and already hosted entries are skipped. Missing entries can be repaired locally; new titles can be added locally. Ambiguous matches require manual review.
